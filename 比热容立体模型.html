比较不同物质的吸热情况 · 3D 并排加热探究

两只烧杯并排放在完全相同的电加热器上，各插一支温度计。 同时加热，水的温度升得慢、食用油的温度升得快 —— 相同热量下升温的快慢，反映的是物质吸热能力的差异， 这个「吸热能力」就是 比热容：Q = c·m·Δt。 三种探究模式：比物质（等质量、等功率）、比质量（同物质、等功率）、比功率（同物质、等质量）。 两种记录方式：① 加热相同的时间 → 比温度变化 Δt；② 升高相同的温度 → 比所用时间 t。

控制变量检查与结论 —

    还没有结论。先把两杯调成等质量、装不同物质，再同时加热。

    实验原理

    1. 转换法：用同一个加热器，加热时间相同 → 两杯吸收的热量相同。
    2. 控制变量：只有质量相同、初温相同、吸热相同，升温快慢才能反映吸热能力。
    3. 不放搅拌器：本实验的器材也可换成砂石、铁等固体颗粒，固体没法搅拌，所以装置里统一不装搅拌器；把物质看作受热均匀，温度计读数就是物质的温度。
    4. 两种记录方式：① 加热相同的时间，比温度变化 Δt（Δt 小的比热容大）；② 升高相同的温度，比所用的时间 t（t 长的比热容大）。两者互为印证：Δt₁:Δt₂ = c₂:c₁、t₁:t₂ = c₁:c₂。
    5. 结论：相同条件下，Δt = Q / (c·m)，升温慢的比热容大。

    水c = 4.2×10³ J/(kg·℃) 食用油c = 2.1×10³ J/(kg·℃) 砂石c = 0.92×10³ J/(kg·℃) 铁c = 0.46×10³ J/(kg·℃)

    水的比热容在常见物质中最大 → 同样吸热升温最慢，所以暖气用水、汽车发动机用水冷却、沿海昼夜温差小。
