潜艇体积不变：注水 → 变重 → 下沉；排水 → 变轻 → 上浮

实验步骤 —— 跟着走一遍，四个现象（做完一格变绿，正在做的是蓝的）

1浮在水面水舱里水少，G 小，F浮 = G，潜艇漂浮。
2注水变重G 变大，F浮 < G，潜艇下沉。
3全浸后浮力不变V排 = 艇体体积，再往下潜 F浮 一点都不变。
4排水上浮G 变小，F浮 > G，潜艇上浮；露出水面后 V排 减小、F浮 也减小。

潜艇为什么能沉能浮

  • 潜艇的体积几乎不变（艇体是硬的钢壳，不像气球会胀缩），所以它无法靠改变 V排 来改变浮力。
  • 它唯一的办法是改变自身重力：艇体两侧有水舱，注水 → 变重 → 下沉；用压缩空气把水压出去 → 变轻 → 上浮。
  • 所以潜艇的原理和鱼不同：鱼靠鱼鳔改变体积，潜艇靠水舱改变重力。这是本节最容易被混淆的一处。
  • 漂浮与悬浮都满足 F浮 = G，区别只在排开体积：漂浮时 V排 < V艇，悬浮时 V排 = V艇。

「完全浸没后浮力不变」——本实验最关键的一条

  • 阿基米德原理 F浮 = ρ水·g·V排：浮力只跟排开液体的体积有关，跟深度无关。
  • 艇体一旦完全浸没，V排 就锁死在艇体体积 V 上。再往下潜 5 m、20 m、40 m，V排 一个立方厘米都不变 ⇒ F浮 完全不变。
  • 右侧「力对比柱」上，绿色（F浮）那条线在潜艇下潜过程中一动不动，只有红色（G）在变 —— 这就是本页要你看的那一幕。
  • 潜艇能停在任意深度（悬浮），靠的不是「越深浮力越大」，而是把 G 调到正好等于 F浮。

常见误区

  • 「潜得越深，浮力越大」？错。完全浸没后 V排 不变 ⇒ 浮力不变。（深度只影响压强，不影响浮力。）
  • 「潜艇靠改变体积沉浮」？错。钢壳体积是固定的，它靠的是改变水舱里的水量，也就是改变重力。
  • 「水舱越满越容易浮」？反了。水舱越满 ⇒ G 越大 ⇒ 越往下沉。
  • 「漂浮和悬浮是一回事」？都是 F浮 = G，但漂浮时只有一部分艇体浸没（V排 < V），悬浮时全部浸没（V排 = V）。

怎么玩（三个对比）

  • 按「快速注水 / 快速排水」：看潜艇一边排气泡一边下沉 / 上浮，同时盯住右侧力对比柱上两条线的距离。
  • 拖「水舱水量」滑块：慢慢加到某个值，F浮 与 G 正好相等 ⇒ 潜艇停在任意深度不动（悬浮）。
  • 拖「海水密度」滑块（1.00 → 1.10）：海水越咸 ⇒ 同样浸没体积的浮力越大 ⇒ 潜艇要装更多水才潜得下去。这就是潜艇进出密度跃层时要重新配平的原因。
  • 拖「潜水艇体积」滑块：艇体越大，全浸时的 F浮 越大，能装的水也越多。反过来把体积调到 500 m³ —— 它全浸时最多只能排开约 515 t 海水，水舱里只要有 20 t 水（总质量 520 t）就浮不住了，直接沉底。
