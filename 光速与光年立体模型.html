结论
  • ①真空中的光速 c = 299 792 458 m/s ≈ 3×10⁸ m/s，是自然界已知最快的速度
  • ②光在介质里变慢：v = c / n。水 2.25×10⁸、玻璃 2.00×10⁸、钻石 1.24×10⁸ m/s（真空里 v = c，这一条不适用）
  • ③「光年」是长度单位，不是时间：1 ly = c × 1 儒略年 = 9.4607×10¹⁵ m ≈ 63241 AU
  • ④我们看到的星光是过去发出来的：光行时间 t = d / v（太阳 8.3 分钟、比邻星 4.25 年、仙女座 254 万年）
  • ⑤光脉冲走够 s = v·t ≥ d 才算到达目标 —— 拖动进度条，这一条会从灭到亮

微波炉测光速 · 巧克力上的融化条纹实拍

把一块巧克力（或一片面包）放进真的微波炉里转十几秒，取出来会看到巧克力上出现一条条等间距的融化带 —— 相邻两条的间隔就是微波的半个波长（家用微波炉 2.45 GHz，λ ≈ 12.2 cm，半波长 ≈ 6.1 cm）。量出这个间隔 d，代入 c = 2·d·f 就能算出约 3×10⁸ m/s。
回到上方实验台：这正是本页想说的 —— c 不是一个背下来的数，而是可以被测出来的；把「传播介质」切到水、玻璃、钻石，看看同一束光换了介质之后速度掉到 c 的几分之几。

三分钟 DIY · 微波炉 + 巧克力测光速实拍

真人把巧克力铺平、进微波炉、取出、量点距、代入公式 —— 整条流程只用到微波炉、巧克力、一把尺子和一个计算器。视频里的每一步都能在上方实验台里找到对应：
「进微波炉加热」= 把「脉冲进度」拖到 100%，让光走完全程；「量融化点间距」= 读侧栏「目标距离 d」那一格；「代入 c = 2·d·f」= 读「目标光行时间 d/v」那一格。注意视频里时间尺度是秒，而光在这一段距离上只花纳秒 —— 这正是本页把「已用时间」写成 ns 的原因。

光调制法测光速 · 大学物理实验室的光具座实验实拍

真实的大学物理实验室：光具座上有一支被高频信号调制的发光二极管和一面反射镜，光走一个来回就产生一个相位差，用示波器把两条波形读出来；把反射镜沿刻度尺移一段距离再读一次，两次读数一联立就解出 c —— 精度比微波炉法高好几个数量级。
注意画面里那条带刻度的导轨：它相当于上方实验台的光尺，只是这里的「尺」量的是几十厘米，而本页的光尺要量到 2.4×10²² m。为什么实验室必须用相位法而不是秒表？看侧栏：光走 1 米只要 3.3 纳秒，秒表根本来不及按。
