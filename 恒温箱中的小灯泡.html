恒温箱中的小灯泡 · 灯丝温度不变，电阻还变吗？

把小灯泡连同灯座放进恒温箱：灯泡照样发光，但通电产生的热被立刻带走， 灯丝温度被钳在设定值一动不动，于是灯丝电阻也不变。拖滑动变阻器改变灯泡两端电压， 看 U/I 是不是同一个数、I–U 图线是不是一条过原点的直线；再点「移出恒温箱」做对照， 温度、电阻立刻跟着电压涨起来。电源、开关、导线、滑动变阻器、电流表、电压表全部取自 2D 电学沙盒， 电流与表针读数由沙盒同一个电路求解内核算出。可全屏投屏、收起参数面板、放大任一器材， 还能切到手动连线让学生自己把电路接起来。

这个实验要证明什么

  • 课本上用定值电阻做「探究电流与电压的关系」，能得到一条过原点的直线， 前提是电阻 R 保持不变。
  • 换成小灯泡就不灵了：电压越高 → 功率越大 → 灯丝越烫 → 钨丝电阻越大， 所以 U/I 一路在涨，I–U 图线向下弯。不是欧姆定律失效，是 R 这个条件没控住。
  • 恒温箱的作用就是把这个变量按住：灯丝发出的热被强制带走，温度停在设定值， 电阻自然一动不动。这时灯泡依然发光，但 U/I 是常数 —— 直线回来了。
  • 所以本实验是控制变量法的一个漂亮例子：控住温度，才轮到谈 U 与 I 成正比。

理想化假设（建议讲给学生听）

  • 恒温箱不是「20 ℃ 的常温箱」：白炽灯要发光，灯丝就得上千摄氏度。 这里设定的是灯丝的某个工作温度（默认 1385 ℃，正是 2.5 V / 0.75 W 小灯泡在额定电压下的灯丝温度），箱内有一套理想强散热装置把它钳住。
  • 通电产生的热量 P = UI 被散热系统全部、即时地带走， 所以「发热 = 散热」、温度不升不降；电压怎么调，温度都由恒温箱说了算，不由功率说了算。
  • 灯丝电阻与温度的关系取自沙盒内核的同一个模型（钨丝正温度系数）：
R(T) = R冷 · [(T + 273.15) / 293.15]1.2
  • 真实实验里很难做到「一点不升温」，但方向是明确的： 只要温度被控住，电阻就基本不变，I 与 U 就成正比。这正是一个理想化模型 帮我们看清主因的地方。

结论与思考

结论：恒温 ⇒ T 不变 ⇒ R 不变 ⇒ I 与 U 成正比， I–U 图像是过原点的直线，斜率 = 1/R；移出恒温箱 ⇒ P↑ → T↑ → R↑ ⇒ 斜率越来越小，图线弯下去。

图上两条线会相交：电压很低时普通灯丝还没热起来， 冷态电阻比恒温箱里那条高温灯丝还小，电流反而更大；电压升高后它才被甩到直线下方。 相交本身就是「R 在变」的证据。

课堂怎么用

  • 投屏演示：点画布右上角 ⛶ 全屏；⚙ 参数面板 可随时收起让画面铺满， 再点一次叫回来。模式、恒温箱温度、电源电压、滑片、开关全部集中在这一块面板里。
  • 看清细节：点 🔍 放大灯泡，或在面板「⑥ 放大查看元件」里任选一件器材； 表针、滑片、灯丝和读数都取自当前这一刻的电路求解结果，不是另画一张示意图。
  • 学生动手接线：「⑤ 连线方式」切到 🔧 手动连线，导线清空。 点一个接线柱、再点另一个就接上一根；点导线中间的编号牌可拆线； ↶ 撤销 / 🧹 清空 / ✅ 按课本接好 随时可用。没接对时两表读不到数，记录按钮也会锁住。
  • 手动连线时照样能拖滑片、点开关、换温度、放大元件 —— 接好线就当场调电压看表针怎么走。
