浮沉判据（两种等价说法）

  • 比力：F浮 > G 上浮 ｜ F浮 = G 悬浮或漂浮 ｜ F浮 < G 下沉
  • 比密度：ρ物 < ρ液 上浮 ｜ ρ物 = ρ液 悬浮 ｜ ρ物 > ρ液 下沉
  • 注意：上浮 / 下沉是过程，漂浮 / 悬浮是终态。上浮的最终结果就是漂浮。
  • 判断顺序：先比 ρ物 与 ρ液 定「上浮还是下沉」，再看有没有露出液面 —— 露出的是漂浮，全浸没的是悬浮。

本实验最漂亮的定量结论

  • 漂浮时 F浮 = G ⟹ ρ液 g V排 = ρ物 g V物 ⟹ V排 / V物 = ρ物 / ρ液
  • 右侧「V排 / V物」这一栏就是它 —— 拖动 ρ物 滑块，看这个比值怎样跟着变。
  • 露出多少？V露 / V物 = 1 − ρ物 / ρ液 —— 拖动 ρ物 滑块，露出水面的部分跟着变。
  • 沉底时球不再平衡：N = G − F浮 > 0（底部支持力补上差额）。

常见误区

  • 「重的物体一定下沉」？错。铁块沉底、铁船能浮 —— 比的是平均密度，不是重量。
  • 「漂浮就是悬浮」？错。漂浮部分露出（V排 < V物），悬浮完全浸没（V排 = V物），两者都满足 F浮 = G。
  • 「上浮的物体会一直升上去」？错。一露出水面 V排 就变小、F浮 跟着变小，到 F浮 = G 立刻停住 —— 这就是漂浮。

怎么玩

  • 拖动画面可旋转视角，滚轮缩放；点「释放小球」让它按真实受力运动到终态。
  • 切到「四态对照」：四个密度不同的小球同槽并排，一次看全上浮 / 悬浮 / 下沉 / 漂浮。
  • 换液体（水 → 盐水 → 酒精 → 汽油），同一个球在 1.20 与 0.70 的液体里终态完全不同。

潜水艇简易模型——探究物体浮沉的条件实拍

真实现场用塑料瓶、吸管和配重做一艘能浮能沉的「小潜水艇」：往艇里加配重，自身重力变大就下沉，减配重就上浮，把上浮、悬浮、下沉三种状态都做了一遍。可对照上方实验台把模式切到「单球探究」，拖「小球密度 ρ物」滑块让读数里的 ρ物/ρ液 依次落到 0.60 / 1.00 / 1.40 —— 「当前状态」卡会跟着在漂浮 → 悬浮 → 下沉之间跳，和视频里一勺一勺加配重的效果一一对应。

【初中物理标准实验课程】物体沉浮的条件实拍

按课堂标准流程走一遍：同一只小球分别放进不同密度的液体里，逐个记录它是浮、是悬、还是沉。建议对照上方「四态对照」模式，重点看「实时数据」表里的「支持力 N」那一行 —— 漂浮和悬浮时它恒为 0，只有沉底以后才变成非零，这正是「沉底后三力平衡 F浮 + N = G」的直接读数，视频里小球压在杯底那一下就是它。
