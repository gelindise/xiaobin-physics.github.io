弹簧模型 · 二力平衡与简谐运动

  • 小球从弹簧上方 h 处由静止释放，先做自由落体（仅受重力）。
  • 接触弹簧后：弹力 F = k·x，随压缩量增大；F 与 mg 相等时达到平衡位置（速度最大）。
  • 继续向下压缩，弹力大于重力，减速至最低点（速度为零、弹性势能最大）。
  • 随后弹力将小球推回，做简谐振动（理想情况下往复不止）。

平衡条件：mg = kx₀ → x₀ = mg/k

能量守恒求最大压缩：mg(h+x_max) = ½kx_max² → x_max = [mg + √(m²g² + 2kmgh)] / k

蹦极模型 · 弹性绳与能量转化

  • 人从跳台跳下，下落距离 < L₀ 时绳松弛，仅受重力、自由落体。
  • 下落距离 > L₀ 时绳开始拉伸，弹力 F = k·(y−L₀)，逐渐增大。
  • 平衡位置在 y = L₀ + mg/k 处（速度最大）；绳拉力 = 重力。
  • 到达最低点时速度为零、弹性势能最大，随后被弹回、上下振动。

平衡条件：mg = k·ΔL₀ → ΔL₀ = mg/k（从绳原长起算）
