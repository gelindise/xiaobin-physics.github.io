小球落弹簧 — 实验说明

  • 小球从弹簧上方 h 处静止释放
  • 接触弹簧后，弹力逐渐增大，加速度逐渐减小
  • 到达平衡位置（mg = kx）时速度最大
  • 继续向下压缩，弹力大于重力，减速至最低点
  • 之后弹簧推动小球向上弹起
  • 点 「✋ 手动模式」可把小球拖到轨迹上任意位置并停住，逐点看清该处的重力、弹力、合力与能量（读数为该位置的真实运动状态）

蹦极模型 — 实验说明

  • 人从跳台跳下，弹性绳原长 L₀
  • 下落距离 < L₀ 时绳松弛，仅受重力，自由落体
  • 超过 L₀ 后绳开始拉伸，弹力逐渐增大
  • 到达平衡位置（mg = k·ΔL）时速度最大
  • 弹力超过重力后减速，到达最低点后弹起
  • 点 「✋ 手动模式」可把人拖到下落轨迹上任意位置并停住，逐点对比重力与弹力（绳未拉直时弹力为 0）

核心公式

平衡条件：mg = kx₀ → x₀ = mg/k

平衡条件：mg = k·ΔL₀ → ΔL₀ = mg/k（从绳原长起算）

最大伸长：½k·ΔL²max = mg(L₀ + ΔLmax)

能量守恒：½mv² + mgy + ½k·ΔL² = 常量

自由落体阶段：绳松弛，仅重力做功
