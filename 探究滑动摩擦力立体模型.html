实验原理

  • 滑动摩擦力 f = μN：μ 是接触面的粗糙程度（动摩擦因数）， N 是垂直于接触面的压力。两个因素缺一不可，与接触面积无关。
  • 弹簧测力计读的是拉力，不是摩擦力。要把拉力「换成」摩擦力，必须满足 水平 + 匀速：此时木块在水平方向上只受拉力和摩擦力，二力平衡 ⇒ F拉 = f。这就是教材说的转换法。
  • 拉力一旦偏离水平 θ，拉力就有了竖直分量：它把木块微微上提 ⇒ N = G·cosθ ÷ (cosθ + μ·sinθ) < G，压力变小、f 也变小， 而读数变成 F拉 = f ÷ cosθ —— 读数不再等于摩擦力。
  • 斜面场景里，压力是重力垂直于斜面的分量：N = G·cos α， 所以 f = μ·G·cos α。α 越大，压力越小，f 越小。
  • 本页的 N、f、读数、检查表、结论、对照图全部由同一个 physOf() 算出，不各写一遍 —— 所以任何一处读数都不可能和别处打架。

操作指南

  • 模式①「压力」：木板、正放、θ = 0°，只改木块上的砝码（0 / 0.5 / 1 / 2 N）。 看 f 与 N 是不是严格成正比，比例系数是不是正好等于 μ。
  • 模式②「粗糙度」：砝码固定，换木板 / 毛巾 / 玻璃板三档 μ，看 f 按 μ 的比值变。
  • 模式③「接触面积」：把木块侧放，接触面积正好减半 —— 读数一点不变。
  • 模式④「斜面」：把木板左端垫高 α（0°~25°），木块会沿斜面下滑。 压力变成 G·cos α，f 跟着按 cos α 变小。α 不够大时木块被静摩擦卡住不动。
  • 拖动空白处旋转视角，滚轮缩放；「侧视」专门用来检查拉力是不是真的水平。

四个问题，一句话答

问题结论为什么
压力变大，f 怎么变？成正比变大f = μN，μ 不变时 f ∝ N
接触面变粗糙，f 怎么变？按 μ 的比例变大N 不变，f 只随 μ 变
接触面积减半，f 变吗？一点不变公式里根本没有面积
拉力斜着拉，读数还是 f 吗？不是斜拉有竖直分量，N 变小、读数≠f
  • 最容易被忽略的一条：滑动摩擦力与接触面积无关。面积减半只是把同样的压力摊在更小的面上， 每个接触点上的压强变大了，但总的阻碍效果不变。
  • 「读数 ≠ f」不代表摩擦力消失了，而是转换法失效了 —— 这时候的读数没有任何物理意义。
